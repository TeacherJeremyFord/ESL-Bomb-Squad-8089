# ESL Bomb Squad — Target Vocabulary (260 Words)

This is the official vocabulary list for Touhu Elementary School students through 6th grade.
Students are expected to know all of these words. They are not expected to know words beyond this list.

> **Note for game design:** If a game instruction uses a word that means the same thing as one of these 260 words, use the 260-word version instead. Longer or less efficient sentences are preferred when they help ESL students understand more clearly.
